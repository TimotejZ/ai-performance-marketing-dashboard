# Lumen Analytics — AI Performance Marketing Dashboard

Simulated **user-acquisition cockpit** for the fictional mobile game **Glow Sculpt**.  
Built as a portfolio piece for **CrazyLabs Marketing Academy 2026** (Skopje).

All campaign numbers, charts, and AI recommendations are **fictional**. They are not live ad-account data.

## What’s inside

- Dark-first UA dashboard (light mode toggle)
- KPI cards: spend, blended ROAS, CPI, installs
- Spend vs revenue line chart and ROAS bar chart (Recharts)
- Filterable campaign table with pause / scale / details
- AI insight cards you can apply or dismiss
- Profile: Timotej Zaevski · UA Lead

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Recharts · Lucide

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build
npm run preview
```

## Note

This repository contains the dashboard application source. Data is hardcoded for demo and interview walkthroughs.
